# Mini Task

Mini Task es una aplicación web ligera, moderna e intuitiva para la gestión de tareas diarias.

El proyecto está diseñado con un enfoque accesible, responsive y de alto rendimiento, desarrollado de forma colaborativa entre desarrolladores utilizando buenas prácticas de control de versiones y estándares de calidad.

## Estado del Proyecto

En etapa de inicialización y desarrollo activo.
